## 7. Restrições & Casos Limite

### 7.1 Restrições Técnicas Absolutas

| Restrição | Detalhe |
|---|---|
| Zero JavaScript no cliente | `output: 'static'` no Astro config garante isso. Nenhum componente pode usar `client:*` directives |
| Sem Node.js APIs em runtime | Esta sprint não tem Worker — não se aplica. O build roda em Node.js normalmente |
| Sem CDN externas para fontes | Inter deve ser self-hosted via `@fontsource/inter` |
| Sem imagens externas | Todos os assets visuais (ícones) são SVG inline no HTML |
| Âncora nativa para scroll | O CTA usa `<a href=\"#features\">` — o browser faz o scroll nativamente, sem `scrollIntoView()` JS |

### 7.2 Comportamentos de Fallback

| Cenário | Comportamento Esperado |
|---|---|
| JavaScript desabilitado no browser | Página funciona 100% — não há dependência de JS |
| Fonte Inter falha ao carregar | Browser usa fallback `sans-serif` — layout não quebra (font-family definida com fallback) |
| Build falha no Cloudflare Pages | Deploy não avança — o Cloudflare Pages mantém a versão anterior deployada |

### 7.3 Compatibilidade de Browser

- CSS Grid e Flexbox: suportados em todos os browsers modernos (Chrome 80+, Firefox 75+, Safari 13+)
- SVG inline: suportado universalmente
- Âncoras HTML (`href=\"#id\"`): funcionalidade nativa HTML — 100% compatível
- Scroll behavior: o `scroll-behavior: smooth` pode ser adicionado via CSS global (sem JS) — **opcional**

### 7.4 Performance Targets

| Métrica | Target |
|---|---|
| Lighthouse Performance | ≥ 95 |
| Lighthouse Accessibility | ≥ 90 |
| First Contentful Paint (FCP) | < 1.0s |
| Total Blocking Time (TBT) | 0ms (zero JS) |
| Cumulative Layout Shift (CLS) | < 0.1 |
